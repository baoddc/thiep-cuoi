# Superpowers Engineering System

This workspace is configured with the **Superpowers** development framework.

## Core Rules & Methodology

1. **Invoke relevant skills before acting**: Always check and invoke relevant skills in `.agents/skills/` before executing tasks or writing code.
2. **Lifecycle Flow**:
   - **Brainstorming** (`.agents/skills/brainstorming/SKILL.md`): Clarify requirements and get human approval before implementation.
   - **Writing Plans** (`.agents/skills/writing-plans/SKILL.md`): Create structured, testable implementation plans.
   - **Test-Driven Development** (`.agents/skills/test-driven-development/SKILL.md`): Follow Red-Green-Refactor cycles.
   - **Systematic Debugging** (`.agents/skills/systematic-debugging/SKILL.md`): Form hypotheses, isolate root causes, and avoid speculative fixes.
   - **Verification Before Completion** (`.agents/skills/verification-before-completion/SKILL.md`): Validate all changes and run tests before finishing.
   - **Code Review** (`.agents/skills/requesting-code-review/SKILL.md` & `.agents/skills/receiving-code-review/SKILL.md`): Ensure high code quality and clean reviews.

Refer to `.agents/skills/using-superpowers/SKILL.md` and `.agents/skills/using-superpowers/references/antigravity-tools.md` for tool mappings and detailed guidelines.
